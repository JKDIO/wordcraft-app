## ★이번 세션에서 바뀐 구조 — 다음 세션은 이걸 먼저 알아야 한다★

### 1. 배포가 자동화됐다 (더 이상 브라우저 드래그 금지)

```
작은 소스 파일 커밋 (app/**) ──▶ GitHub Actions wc-build ──▶ 루트 main.js·app.css ──▶ Vercel 자동배포
```

- **소스 트리는 저장소 `app/` 에 있다.** (예전처럼 tgz만 있는 게 아니다)
- CSS는 `app/public/css.d/NN-이름.css` 조각으로 추가한다. **`app.css`를 통째로 고치지 않는다.**
- CI 결과는 `_ci/BUILD_REPORT.txt`(크기·sha256·gzip)로 되돌아온다 — 460KB를 읽을 필요가 없다.
- 수동 재빌드: `_ci/build.txt` 를 아무 내용으로 커밋.
- 안전장치: 번들 300KB 미만이면 CI 실패(깨진 빌드가 라이브를 덮는 것 방지).

### 2. 이미지 자산도 자동화됐다

```
fal.ai URL ──▶ SQL(pg_net) ──▶ Edge Function art-forge ──▶ Storage art/hero/*.png
                               Edge Function art-layer ──▶ Storage art/hero/layer/*.png
```

- 이미지 바이트가 **모델 문맥을 통과하지 않는다.** 사용법은 프로젝트 메모리 `앱개발/자동화_이미지자산_파이프라인_v1.md`.
- 현재 자산: 베이스 1 + 합본 44 + 투명 레이어 44 (11슬롯 × 4등급).

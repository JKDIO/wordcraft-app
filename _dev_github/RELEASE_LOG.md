  - **T10은 대륙의 결말**이다. V10-15부터 무자의 기척이 짙어지고, 마지막 V10-20은 **싸워 이기는 게 아니라 무자에게 이름을 지어 주는 것**으로 끝난다(오답을 처벌하지 않는 앱이니 마지막 적도 처벌로 끝내지 않는다).

### 수정 2 — 분류 상자 🗃️ (네 번째 입력 방식)
- **12칩을 한 화면에 늘어놓고 상자에 나눠 담는다.** 문항을 하나씩 맞히는 게 아니라 **서로 견주게** 하는 활동 — 규칙을 설명해 주지 않고 예에서 발견하게 하는 귀납 학습(블루프린트 원리 6).
- **기준 두 가지**: ① 품사가 섞여 있으면 **품사**(이름/움직임/꾸밈/도움/자리/이음/덩어리 상자) — GIU Basic의 뼈대가 공짜로 따라온다. ② 전부 같은 품사면 **음절 수**(손뼉 1·2·3번) — 듣기·발음의 토대.
- **적용 범위 189/200팩.** 처음엔 품사만 써서 38/200에 그쳤다(= 해금 안내만 뜨고 실제로는 안 나오는 상태). `phr` 품사 추가 + 1개짜리 그룹 버리기 + 상자 최대 3개로 잘라내기 + 음절 대안까지 넣어 189까지 올렸다.
- 분류가 붙는 팩은 문항 상한을 28 → **20**으로 줄여 세션 15~20분 예산을 지켰다.
- **스모크가 잡은 UX 결함**: 상자가 차면 '상자 빈 곳'이 좁아져서, 넣으려고 누른 손가락이 **이미 담긴 단어를 도로 꺼내 버렸다.** 단어를 집어 든 상태에서는 상자 안 칩이 클릭을 먹지 않도록 봉합(아이 손가락은 더 굵다).

### 수정 3 — 속사 사냥 🔥 (선택형 유창성 라운드)
- 팩을 끝낸 뒤 **선택**으로 들어가는 45초 라운드. 단어–뜻이 맞는지 ⭕/❌만 빠르게 누른다. 목적은 정확도가 아니라 **자동화(automaticity)** — 아는 것을 '빨리' 꺼내는 훈련.
- **의도적으로 기록하지 않는다**(answer_events·XP 없음). 속도 게임을 점수에 넣으면 ① 관제실 정답률이 오염되고 ② 아이가 **급하게 찍는 습관을 보상받는다.**
- **L24의 재판을 미리 막았다**: 처음엔 해시로 55%를 짝으로 뽑았더니 어떤 팩은 24장 중 20장이 ⭕가 됐다 — 그러면 단어를 안 보고 ⭕만 연타하는 게 최적 전략이 된다. **정확히 7/12를 짝으로 고정**하고 두 바퀴의 조합을 다르게 잡아 봉합. 200팩 전수 재계측 결함 0.

### 수정 4 — 단어 골렘 보스전 ⚔️ (팩 5개마다, 전체 40회)
- 그 티어의 팩을 5·10·15·20개 정복할 때마다 지도에 골렘이 나타난다. 몸에 박힌 단어 = **직전 5팩 60단어에서 뽑은 12개**(다섯 팩에서 균등하게).
  - 교육적 근거: 팩 직후가 아니라 **몇 팩 지난 뒤** 다시 만나므로 **간격 반복**, 다섯 팩을 섞으므로 **교차 연습**. 즉 보스전 자체가 누적 복습이다.
- **실패가 없다.** 틀리면 골렘이 그 단어를 다시 삼키고 그 문항이 **큐 맨 뒤로 돌아온다** — 12칸을 다 깰 때까지 반복되는 **완전 학습(mastery learning)**. 감점도, 재도전 실패도 없다.
- **길을 막지 않는다.** 무시하고 다음 팩으로 가도 된다(자기결정). 다만 잡아야 수호자가 한 단계 깨어난다.
- 자기 채점 모드(`speak`)는 보스전에서 제외 — 자기 채점으로는 갑옷이 공짜로 깨진다.
- 기록: `activity_type='vocab'`, `module_id='GOLEM-T<티어>-<번호>'`. **스키마 변경 0.** XP: 문항 정답 5 + 격파 보너스 **40**(신규 `XP.vocabGolem`, 세 곳 단일 정의).

### 수정 5 — 해금 곡선을 '티어'에서 '누적 정복 팩 수'로

  - 수정: `ensureFreshSession()`(만료 임박 시 선제 갱신) + `getAuthUser()` 실패 시 **리프레시 1회 재시도 후에만** 로그아웃 판정 + `refreshSession()`은 **400/401/403일 때만** 세션 폐기(네트워크 끊김·5xx로 오프라인 로그아웃 금지) + 신규 `ensureAnonSession()`(살아있는 세션 재사용).
- **P0-2. 보호자 기기가 아이 기기로 강등될 수 있었다**
  - 보호자 구글 세션이 만료되면 role이 `legacy`로 떨어지고, 로컬에 learnerId가 있으면 **익명 로그인 + 그 아이에 device 바인딩**까지 실행됐다.
  - 수정: 기기 정체를 세션과 분리해 기억(`wordcraft_auth_kind_v1`). 보호자 기기는 세션이 끊겨도 강등하지 않고 **가족 화면의 재로그인**으로 보낸다. FamilyDashboard에 **"구글로 다시 로그인"** 화면 신설(종전엔 쓸모없는 가족코드 입력 폼만 떴다).
- **P0-3. 아이 딥링크 재방문마다 새 계정** — `Connect`의 원터치 시작이 조건 없이 `signInAnonymously()`를 호출했다. → `ensureAnonSession()`으로 교체.
- **P1. 보호자가 실제로 연결했는지 볼 방법이 없었다** — 그래서 **진영이네가 한 번도 로그인하지 않은 것을 아무도 몰랐다**(guardians=0, 아이 찬영·호영 XP 0). 슈퍼 관리실에 **보호자 연결 현황**(관계·가입일·마스킹 이메일·아이 기기 수) 표시 + 미연결이면 경고 배너. 소유자용 **가족 정보 수정**(가족명·부모명) 추가 — 예한이네 `parent_name`이 null인 채 앱에서 고칠 방법이 없었다.
- **P1. 보호자 대시보드 아이별 한눈 요약** — 오늘 학습 분(15분 달성 표시) · 최근 7일 정답률 · 밀린 복습 카드 · 최근 학습일. 한 번도 시작 안 한 아이는 **"⏳ 아직 시작 전 — 링크를 보내주세요"**로 명시. 다른 보호자(엄마·조부모) 초대문구 복사 버튼 추가(종전엔 소유자만 만들 수 있었다).

# v1.4.32 — 2026-08-14 (오타 수정 + 장비칸↔분야 연결 명확화)

Dio님 지적 2건에 대한 즉시 수정.

## 1. '뭃지' 오타 (P0 — 아이 화면에 노출됨)

- 장비창 안내문이 라이브에서 **"그 분야 뭃지로 바로 간다"** 로 나갔다.
- 원인: GitHub API로 소스를 올릴 때 한글을 유니코드 이스케이프로 손수 적다가 `뱃`(U+BC43)을 `뭃`(U+BB43)으로 한 자리 틀렸다. **로컬 소스는 정상이었고 전송 과정에서만 깨졌다.**
- 조치: 수정 + **앞으로 한글은 이스케이프 없이 UTF-8 그대로 전송**. 교훈 L36 제정.

## 2. 장비칸과 분야의 연결이 안 읽힘

- 지적: *"각 그룹과 장비를 묶는 연결이 좀 명확하지 못한 것 같아. 아이콘 크기를 키울 수 없다면 순서라도 일치하게."*
- 원인: `LOADOUT_SLOTS` 순서가 `BadgeGroup` 선언 순서(= 뱃지 도감 순서)와 달랐다. '소리와 철자'가 도감에선 2번째인데 장비칸에선 7번째였다.
- 조치:
  1. **장비칸 순서를 뱃지 도감과 완전히 일치**시켰다 (`loadout.ts`에 규칙으로 주석 고정)
  2. **장비 아래에 분야 이름을 직접 표기** — 이모지 하나로는 어느 분야인지 안 읽힌다
  3. 분야 이름이 들어갈 폭을 위해 **4열 → 3열** (360px 미만은 2열)
  4. 장비 이모지 22px → 26px

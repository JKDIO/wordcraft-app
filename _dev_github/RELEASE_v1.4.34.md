## v1.4.33 — 자산 캐시 무효화 + 곡괭이 위치 수정

**Dio님 지적**: *"곡괭이는 오른손에 있어야 하는 거 아냐? 칼이랑 겹쳐 있는데?"* → 이어서 *"리프레쉬 해도 곡괭이 위치가 바뀌지 않아."*

### 결함 ① 곡괭이 1·3등급이 검과 같은 쪽
- 원인: 44 레이어 생성 시 `held in his LEFT hand` 라고만 써서 모델이 **등급마다 다르게 해석**했다. 2·4등급은 화면 왼쪽, 1·3등급은 오른쪽.
- 검수가 못 잡은 이유: **레이어를 하나씩만 봤다.** 겹침은 조합해야 보인다.
- 조치: `LEFT HALF of the image` / `RIGHT HALF must remain empty` 로 화면 기준 재생성 → art-forge → art-layer. 교훈 **L37**.

### 결함 ② 고쳤는데 화면이 안 바뀜
- 원인: Supabase Storage `Cache-Control` 1시간. 파일명이 같으면 브라우저·WebView가 옛 바이트를 계속 쓴다.
- 내 검수가 못 잡은 이유: 캐시버스터를 붙여 보고 있었다 — **사용자와 다른 경로**를 본 것.
- 조치: `heroSprite.ts`에 `ART_VER` 상수를 두고 모든 자산 주소에 `?v=` 부착. 그림을 고치면 이 숫자를 올린다. 교훈 **L38**.

## v1.4.34 — 등급 상승 연출

장비는 뱃지를 딴 그 순간이 아니라 **다음에 장비창을 열 때** 바뀌어 있다. 표시가 없으면 아이는 뭐가 달라졌는지 모른 채 지나간다.

- 마지막으로 본 슬롯 등급을 localStorage(`wc_loadout_seen_v1`, 신규 키 — L17 준수)에 기억
- 올라간 슬롯만 금색으로 튀어오르고(2.4초), 기사가 한 번 번쩍이고, 마법진이 빨라지고, 안내문이 `✨ 검·곡괭이 업그레이드!` 로 바뀐다
- **처음 여는 경우(기록 없음)는 축하하지 않는다** — 전부 반짝이면 의미가 없다
- CSS 애니메이션만 사용(Web Animations API·canvas 금지 — L8), `prefers-reduced-motion` 존중

## 1. ✍️ 자유 작문 채점기 (설계 문서 §C 이행)

- 채점은 **서버(Edge Function `write-grade`)** 가 한다. 앱 번들에 API 키가 없고, 아이가 결과를 손댈 수 없다.
- 레인은 지시대로 **OpenRouter T1~T2**(`deepseek-v4-pro` → `deepseek-v4-flash`). Claude 호출 0.
- `audit_mode: true` — 2주 감사 모드. 모든 판정이 `write_grade_logs` 에 남고 관제실 ✍️작문 탭에서 본다.
- `answer_events` 기록은 **additive**: `activity_type='write_free'` 신설, 기존 컬럼·스키마 변경 0(L17).
  정답이 없으므로 `correct_answer` 를 **비운다** — 관제실이 '정답'을 보여주면 그건 거짓말이다.
- 정답률·연속 정답 스트릭에서 **제외**한다(L28). 작문이 섞이면 실력 지표가 거짓이 된다.

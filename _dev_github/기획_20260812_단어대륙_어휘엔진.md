> 앱이 실제로 가르치던 표제어 **428개**, 전체 음성 텍스트의 고유 단어 **623개**.

## 0. 왜 "모듈 추가"가 아니라 "엔진"인가
2,400단어를 지금까지의 방식(손으로 짠 스토리 모듈)으로 덮으려면 모듈 200개를 저작해야 한다. 회차도 회차지만,
**개인화가 불가능**하다는 게 더 큰 문제다. 아이마다 아는 단어가 다른데 모두에게 같은 순서를 강요하면
아는 단어에서 지루해지고 모르는 단어에서 무너진다. 그래서 **데이터(단어) + 규칙(엔진)** 으로 분리했다.
기존 월드·스토리·유령·소환진은 **그대로 보존**하고, 어휘만 별도 대륙으로 붙인다.

## 1. 구조
- **10티어 × 20팩 × 12단어 = 2,400단어.** 팩 하나 = 5~7분(예한이 집중 15~20분 안에 2~3팩).
- 티어 = 난이도 사다리이자 세계관의 땅.

| 티어 | 이름 | 성격 | 출처축 |
|---|---|---|---|
| 1 | 새싹 들판 | 이미 아는 단어로 몸풀기 | Dolch/Fry + 교육부 초등 |
| 2 | 돌다리 마을 | 눈에 보이는 것들(구체 명사·기본 동사) | 교육부 초등 800 |
| 3 | 바람 언덕 | **GIU Basic 예문 핵심**(기능어 다수) | GIU Basic |
| 4 | 안개 숲 | 기본어의 정밀화(shout/whisper 류) | GIU + 초등 확장 |
| 5 | 수정 협곡 | 학교생활 + 문장 연결어 | 기능어 + 학교 |
| 6 | 강철 성채 | 중1 — 사람·관계·감정·문화·진로 | 중1 교과서 |
| 7 | 폭풍 항구 | 중2 — 자연·과학·기술·사회 | 중2 교과서 |

| 10 | 용의 왕좌 | 중학 졸업 관문 + 고교 진입 | 접두사·구동사·불규칙·혼동쌍 |

## 2. "질려서 안 하는 불상사"를 막는 장치 (Dio님 최우선 요구)
1. **사전 스캔** — 팩을 시작하면 12단어를 하나씩 보여주고 **"알아요 / 몰라요"를 아이가 직접 고른다.**
   아는 단어는 학습 카드와 문항에서 빠지고, 복습 카드는 **박스 3부터** 시작한다.
   → 이탈의 1순위 원인은 어려움이 아니라 **아는 걸 또 시키는 지루함**이다. 이걸 구조로 없앤다.
   → 부수 효과: 아이가 "내가 정한다"는 감각을 갖는다(자기결정이론).
2. **티어 1~2를 일부러 쉽게** — 이미 아는 단어로 채운다. 첫 30분에 "이거 나 다 알잖아?"가 나와야 한다.
   여기서 어려운 단어가 하나라도 튀면 아이는 시스템 전체를 어렵다고 판정한다.
3. **한 팩 안의 난이도를 고르게** — 팩 안에 혼자 튀는 단어가 있으면 그 팩 전체가 싫어진다(저작 규격에 명시).
4. **팩을 3개씩 열어 고르게** — 강제 순서가 아니라 선택. 티어는 앞 티어 80% 정복 시 개방.
5. **오답 = 리스폰.** 감점·질책·비교 문구 0. 결과 화면의 칭찬은 능력이 아니라 **전략과 노력**에 준다.
6. **힌트 3단계**(품사 → 첫 글자 → 연상 단서) — 바로 주지 않되, 막히면 반드시 빠져나갈 길이 있다.

## 3. 게임 5종 (교차 연습)
| 모드 | 하는 일 | 인출 방향 | 적용 원리 |
|---|---|---|---|
| 🎯 뜻 사냥 | 영어 → 한국어 뜻 고르기 | 재인 | 인출 연습 |
| 🎣 소리 낚시 | 음원 듣고 단어 고르기 | 청각 → 형태 | 이중 부호화·듣기 |
| 🧩 문장 구멍 | 예문 빈칸 채우기 | 문맥 | 맥락 학습 |
| 🔨 철자 대장간 | 빠진 글자 채워 입력 | 산출(철자) | 출력 가설 |
| 🪄 한→영 소환 | 한국어 → 영어 고르기 | **가장 어려운 인출** | 바람직한 어려움 |

- 모르는 단어 = **서로 다른 두 모드**로 2문항, 아는 단어 = 확인용 1문항. 팩당 최대 28문항.
- 같은 단어가 연달아 나오지 않게 재배치한다.
- 오답 선택지는 **같은 품사 + 같은 의미장**(뜻 사냥은 같은 팩의 다른 단어에서 뽑으므로 자동으로 같은 의미장).

## 4. 기존 시스템과의 연결
- **복습 광산(라이트너)**: 팩을 끝내면 12단어가 전부 복습 카드로 들어간다(`card_id='vocab:<단어>'`).
  → 어휘 엔진이 매일의 복습량을 자동으로 채워준다. 간격 반복은 기존 엔진 그대로.
- **오늘의 밸런스(모험:복습 50:50)**: 어휘 XP는 '모험'으로 분류된다.
- **스키마 변경 0**: 팩 진도는 `module_progress`(module_id='V3-07'), 문항은 `answer_events`(activity_type='vocab').

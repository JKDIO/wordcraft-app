이 도구는 배포 전 필수 관문이다 (LESSONS L22).
content.json의 모든 audio_url을 실제로 내려받아 디코딩해 파형을 측정한다. "파일이 존재한다"는 검수는 무음 클립을 통과시킨다 — 2026-08-01에 실제로 10개가 그렇게 새어나가 예한이가 학습 중 소리 없는 문항을 만났다. 그래서 판정 기준은 파형(RMS·peak)이다.

판정 기준

무음 peak < 0.05 또는 RMS < 0.01 → 결함
초단축 무음 구간을 뺀 발화 길이 < 0.15초 → 결함
부재 HTTP 200이 아니거나 디코딩 실패 → 결함
TTS 의존 재생 텍스트(tts)는 있는데 audio_url이 없음 → 위험 (예한이 폰 APK WebView는 TTS 보이스가 비어 조용히 실패한 전력이 있다 — L19)

참고(2026-08-01 v1.4.15 기준선): 정상 클립의 최저값은 peak 0.237 / RMS 0.0231이었고, 무음 클립은 peak 0.000~0.003이었다. 두 집단이 완전히 갈리므로 이 문턱값은 안전하다.
이 도구가 잡지 못하는 것: "소리는 나는데 다른 단어를 말한다"는 사람이 들어야 한다. 결함 0을 확인한 뒤에도 새로 만든 클립은 표본 청취를 할 것.

## 11. 2026-08-29 3차 재시도 — 모델 교체로 화풍 문제 해결

### 배경
Dio님 지시: "아직 부족해. 완전히 만족할만한 결과가 나올 때까지 진행해줘." 2차까지 같은 모델(`flux-pro/kontext`)로 프롬프트만 바꿔 2연속 실패했으므로, §7-6에서 제시한 대안 중 "다른 모델 시도"를 실행했다.

### 실행 내용
같은 원본(`ASSETS.heroKnight`)에 `fal-ai/nano-banana-pro/edit`(Google Nano Banana Pro)을 적용. 프롬프트는 2차와 동일한 요구사항(화풍 고정·뿔 금지·로고 금지·평범한 옷·회색 배경)을 유지했고 모델만 교체했다.

**⚠️ 도구 사용법 주의(Claude Code 이관 시 반드시 참고)**: `fal-ai/nano-banana-pro/edit`은 fal MCP의 `edit_image` 전용 래퍼 도구로 호출하면 "Unprocessable Entity" 오류로 실패한다. 대신 범용 도구 `run_model`(model=`fal-ai/nano-banana-pro/edit`, input=`{"prompt": "...", "image_urls": ["<url>"]}`)로 호출해야 성공한다 — 이 모델(Gemini/nano-banana 계열)은 `edit_image` 래퍼가 가정하는 필드명과 다른 입력 형식(`image_urls` 배열)을 기대한다.

### 결과 — 3개 기준 전부 통과
- **화풍(O4-2) — PASS.** 실제 붓터치가 보이는 페인터리 일러스트로 나왔다. 사실적 사진풍이 아니다.
- **뿔(O4-3) — PASS.** 없음.
- **로고(O4-4) — PASS.** 없음, 텍스트·엠블럼 없음.
- **캐릭터 동일성(O4) — 대체로 PASS, 단 참고 사항 있음.** 같은 계열의 검은 머리·젊은 얼굴형이지만, 손을 모으고 있는 새 포즈로 나와 원본의 "검을 든 자세"와는 다르다(장비를 다 벗겼으니 자연스러운 결과). 이목구비가 원본보다 살짝 또렷하게(광대·음영) 재해석됐다 — 완전히 동일한 픽셀 수준은 아니고 "같은 캐릭터로 인식 가능한 수준"이다.

### 판정: 성공 후보 — Dio님 최종 확인 대기
3개 P0 기준(화풍·뿔·로고)을 전부 통과한 첫 결과물이다. 캐릭터 동일성은 완벽 일치는 아니지만 이 정도 편차는 본 생산 단계에서 시드·레퍼런스 이미지 고정으로 좁힐 수 있는 범위로 판단한다(추정 — 실제로 본 생산 1~2장을 더 만들어봐야 확정 가능).

## 12. 본 생산 규격 (v2.0 신규 정본 — 2026-09-03 확정)

### 12-1. 캔버스
| 항목 | 값 | 근거 |
|---|---|---|
| 캔버스 | **896 × 1200** | `nano-banana-pro/edit` 이 실제로 내놓는 크기. 800×1200은 잠정값이었고 리사이즈는 붓터치를 뭉갠다 |
| 정렬 | **풀-블리드 고정** — 베이스와 장비본은 같은 캔버스에서 같은 자리에 선다 | 좌표 오프셋을 두지 않는다. 겹치기만 하면 맞는다 |
| 배경 | 평평한 밝은 회색, 배경 소품 없음 | 차분에 배경이 끼면 오염된다 |
| 형식 | 레이어는 **RGBA PNG**, 베이스는 RGB PNG | |

### 12-2. 슬롯 × 등급 (6 × 4 = 24장)
슬롯: `helm` · `cloak` · `shoulder` · `chest` · `gloves` · `boots`
등급: `t1`(가죽) · `t2`(철) · `t3`(강철·문양) · `t4`(황금·룬)
※ HERO_SPEC의 t0(맨몸)은 베이스 그 자체이므로 레이어를 만들지 않는다.

### 12-3. 파일명 — `pixelize.py` 명명 관습 준용
```
art/gallery/base.png                 베이스 바디 (896x1200, RGB)
art/gallery/layer/<슬롯>_<등급>.png   장비 레이어 (896x1200, RGBA)
  예: layer/helm_t3.png · layer/boots_t1.png
```
중간 산출물(장비를 입은 통짜 그림)은 `_fal_test/raw/<슬롯>_<등급>.png` 에 남긴다 —
**버리지 않는다.** 레이어를 다시 뽑아야 할 때 fal을 다시 부르지 않아도 된다(비용).

### 12-4. 생성 (모델·프롬프트)
모델은 **`fal-ai/nano-banana-pro/edit`** 고정. 호출은 반드시 범용 도구 `run_model` 로:
`input = {"prompt": "...", "image_urls": ["<베이스 URL>"]}` (전용 래퍼 `edit_image` 는 실패한다 — §11)

프롬프트 골격(모든 슬롯 공통):
```
Keep this exact image completely unchanged — same character, same face, same clothing,
same pose, same background, same canvas size, same body position and scale —
and change ONLY the <부위>: <장비 구절>.
Match the existing hand-painted painterly brushwork exactly.
STRICTLY FORBIDDEN: horns, horned helmet, devil horns, demon horns, antlers,
curved side ornaments resembling horns, or any horn-like shape;
closed helmet hiding the face; logos, emblems, heraldry, text, signature, watermark;
photorealism, photograph, 3D render.
```
> ★뿔 금지 구절은 HERO_SPEC §5의 문구를 그대로 쓴다 — **헬멧류뿐 아니라 전 슬롯에 넣는다.**
> 어깨 장식·망토 고리에서도 뿔 모양이 나올 수 있다. 신앙 기준, Dio님 절대 요구사항이므로 예외 없다.
> ★`closed helmet hiding the face` 도 유지한다 — 얼굴 없는 영웅은 아이가 자기라고 느끼지 못한다.

### 12-5. 레이어 추출 — `app/tools/overlay_layer.py` (2026-09-03 신설)
```bash
python3 tools/overlay_layer.py base.png raw/helm_t3.png layer/helm_t3.png         --region head --preview
```
하는 일: 베이스 대비 차분 → 작은 점 덩어리 제거 → 구멍 메우기(binary_closing + fill_holes)
→ 알파 생성 → **부위 밖 오염도 검사** → 원자적 저장.

이 방식이 성립하는 근거(실측 2026-09-03, helm t3 파일럿):
```
캔버스 896x1200 · 변경 20,250px (1.88%) · 노이즈 제거 440px
바운딩박스 x 370~515 · y 13~262
부위 'head'(0.00~0.28) 밖 변경 0px (0.00%)
```
**모델이 지시한 부위 외 캔버스를 건드리지 않는다**는 것이 수치로 확인됐다. 이 전제가 깨지면
오염도 검사가 먼저 운다(`--region feet` 로 일부러 틀리게 주면 100% 로 실패하는 것까지 확인).

슬롯별 `--region` 기본값: helm=`head` · shoulder=`shoulder` · chest=`torso` ·
cloak=`cloak` · gloves=`hands` · boots=`feet`

### 12-6. 합격 기준 (통과 못 하면 재생성 — 사람이 눈으로 본다)
| # | 기준 | 판정 방법 |
|---|---|---|
| O1 | **뿔이 없다** | 사람이 본다. 자동 검사 없음 — **Dio님 절대 요구사항이라 기계 판정에 맡기지 않는다** |
| O2 | 로고·문자·워터마크가 없다 | 사람이 본다 |
| O3 | 화풍이 베이스와 같다(붓터치 보임, 사진풍 아님) | 사람이 본다 |
| O4 | 얼굴이 가려지지 않는다(헬멧류) | 사람이 본다 |
| O5 | 오염도 ≤ 5% | `overlay_layer.py` 가 자동 판정 |
| O6 | 레이어가 비어 있지 않다 | 자동 판정(exit 3) |
| O7 | 캔버스가 896×1200이다 | 자동 판정(exit 2) |

### 12-7. 알려진 한계 (파일럿에서 실제로 보인 것 — 본 생산 전에 읽을 것)
1. **경계에 회색 후광이 남는다.** 장비 가장자리에서 베이스 배경색이 딸려 온다. `--thresh` 를 올리면
   줄지만 얇은 부분(깃털·끈)이 끊긴다. 24가 지금까지 가장 나은 절충이다 — **본 생산 24장을 뽑아 보고 다시 정한다.**
2. **가느다란 부속이 조각난다.** 파일럿에서 턱끈 일부가 떨어져 나왔다. `--min-blob` 을 낮추면 살지만
   노이즈도 같이 산다.
3. **얼굴 구멍은 의도된 투명이다.** 투구 눈구멍으로 배경이 비치는 것은 결함이 아니다 —
   아래 베이스의 얼굴이 그 자리에 있어야 한다.
4. **캐릭터 나이대**가 원본보다 청년에 가깝다(B5). Dio님 보류 — 24장 생산 후 화면에서 재판단.

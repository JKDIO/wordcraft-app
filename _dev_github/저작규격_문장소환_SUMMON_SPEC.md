# 🔮 문장 소환 저작 규격 v1.0 (v1.4.24) — 저작 에이전트 필독

예한이(초6, 한국인)를 위한 영어 학습 앱 WordCraft의 새 스텝 **`summon`(문장 소환)** 콘텐츠를 만듭니다.

## 0. 이게 뭔가 — 한 문장으로

**아이가 블록으로 문장을 조립하면, 그 문장이 무대에서 그대로 실행된다.**
"The dog eats the cat"을 만들면 강아지가 고양이를 먹는다. 케이크를 먹지 않는다. 이 약속이 이 기능의 전부다.

원래 월드 6의 독립 화면이었으나 v1.4.24에서 **문법을 다루는 모든 단원 안의 한 스텝**으로 옮겼다.
아이는 그 단원에서 방금 배운 문법을 **그 자리에서 직접 조립해 실행**해 본다.

## 1. 어디에 넣는가

각 모듈 `steps` 배열에서 **마지막 `quiz` 바로 앞**에 삽입한다.

```json
{ "type": "summon",
  "prompt_ko": "🔮 마법진에 블록을 올려 문장을 소환해! 문법이 맞아야 실행된다 ⚡",
  "items": [ ...정확히 3개... ] }
```

`prompt_ko`는 그 단원 캐릭터의 말투로 한 줄(40자 이내, 이모지 1~2개). 모듈마다 다르게 쓴다.

## 2. item 스키마 (한 글자도 어기지 말 것)

```json
{
  "id": "C7-SM-1",
  "ko": "강아지가 케이크를 빠르게 먹어!",
  "tokens": ["The dog", "eats", "the cake", "fast", "eat", "The cake"],
  "answer": "The dog eats the cake fast",
  "focus_ko": "3인칭 단수 주어엔 동사에 왕관 -s",
  "explain_ko": "The dog는 한 마리(3인칭 단수)라 eat이 아니라 eats! 빠르기는 맨 끝에 붙어.",
  "scene": { "actor": "dog", "verb": "eat", "object": "cake", "speed": 1.7 },
  "tts": "The dog eats the cake fast",
  "voice": "nova"
}
```

| 필드 | 규칙 |
|---|---|
| `id` | `<모듈>-SM-1` ~ `-SM-3`. **전역 유일** |
| `ko` | 미션(한국어 뜻). 40자 이내. 이걸 보고 영어로 조립한다 |
| `tokens` | **정답 토큰 + 오답 블록 1~2개**. 총 4~7개. 오답 블록은 그럴듯해야 한다(동사 원형, 다른 주어, 틀린 시제 등) |
| `answer` | 정답 문장. **마침표 없음.** 정답 토큰만 순서대로 공백으로 이으면 **정확히 이 문자열** |
| `focus_ko` | 이 단원의 문법 초점 한 줄(30자 이내). 틀렸을 때 힌트로 뜬다 |
| `explain_ko` | 정답 후 해설(60~120자). 왜 그 순서·그 형태인지 |
| `scene` | **재현 가능할 때만.** §3 참조. 불가능하면 **넣지 마세요**(생략) |
| `tts`/`voice` | `answer`와 같은 순수 영어 문장 + `"nova"`. **항상 짝** |

### 검증 규칙 (스크립트가 봅니다)
- `answer`의 각 단어열이 `tokens` 안에 **정확히** 존재해야 한다 → `answer`를 tokens 부분집합으로 분해 가능
- `tokens`에 중복 문자열 금지
- 오답 블록이 **정답의 일부로 쓰일 수 없어야** 한다(그러면 정답이 여러 개가 된다)
- ⚠️ **다른 순서로 조립해도 정답과 뜻이 같은 문장이 되면 안 된다** — 아이가 맞혀도 틀렸다고 나온다

## 3. `scene` — 무대에서 재현 가능한 문장에만

무대에는 **정해진 배역과 동작만** 있다. 문장이 아래 표 안에서 만들어질 때만 `scene`을 넣는다.

| 필드 | 가능한 값 |
|---|---|
| `actor` (주어) | `zombie`(The zombie 좀비) · `bomb`(The monster 폭탄몬) · `cake`(The cake 케이크) · `dog`(The dog 강아지) · `cat`(The cat 고양이) |
| `verb` (동사) | `jump` `run` `eat` `sleep` `dance` `fly` `cry` `laugh` `spin` `fall` `explode` `hug` |
| `object` (목적어) | `eat`·`hug`에만. 위 5종과 같음 (the cake / the monster / the dog / the cat / the zombie) |
| `speed` | `fast`=1.7 · `slowly`=0.55 · 없으면 생략 |

**동사 제약(반드시 지킬 것)**
- `hug`는 **목적어 필수** (`The dog hugs the cat`)
- `eat`은 목적어 **선택**
- 나머지 10개는 목적어를 붙일 수 없다 (`The cat sleeps the dog` ✗)
- 주어는 전부 3인칭 단수 → 동사는 항상 `-s` 형태 (`jumps` `runs` `eats` `flies` `cries` …)

**★scene을 넣었으면 문장과 100% 일치해야 한다.★**
`The cake explodes`의 scene은 `{actor:"cake", verb:"explode"}`다. 폭탄몬이 아니다.
`The dog eats the cat`의 scene은 `{actor:"dog", verb:"eat", object:"cat"}`이다. 케이크가 아니다.
어긋나면 아이는 "내가 만든 문장이랑 화면이 다르네"를 배운다 — 이 기능의 신뢰가 그 자리에서 끝난다.

**scene을 넣을 수 없으면 생략한다.** 그러면 앱이 문장을 의미 덩어리 단위로 마법진에 **새기는 연출**로 간다.
아무 애니메이션이나 갖다 붙이지 마세요. 정직한 연출이 거짓 연출보다 낫습니다.

## 4. 3문항의 난이도 설계 (모듈마다 동일)

| # | 성격 | 요구 |
|---|---|---|
| SM-1 | **기본** — 이 단원 규칙을 그대로 적용 | 토큰 4~5개, 오답 블록 1개 |
| SM-2 | **확장** — 규칙 + 요소 하나 더(목적어·부사·시간 표현 등) | 토큰 5~6개, 오답 블록 1~2개 |
| SM-3 | **함정** — 한국어 화자가 흔히 틀리는 지점 | 토큰 5~7개, 오답 블록 2개 |

**가능하면 SM-1과 SM-2 중 최소 1개는 `scene`이 붙도록** 문장을 설계하세요(아이가 캐릭터 애니메이션을 본다).
단, 그러려고 단원의 문법 초점을 버리면 안 됩니다 — **초점이 우선**입니다.

## 5. 콘텐츠 헌법 (전부 적용)

1. **무조건 재미있어야 한다.** 딱딱한 설명 금지. 캐릭터가 말하듯이.
2. **오답 = 리스폰.** 감점·질책·비교·"이것도 몰라?" 류 금지.
3. **칭찬은 능력이 아니라 전략·노력에.** "똑똑하다" 금지.
4. **한국어 화자 맞춤** — 어순·관사·수일치·주어 생략·후치수식의 차이를 `focus_ko`·`explain_ko`에서 짚는다.
5. **i+1** — 그 모듈이 이미 가르친 어휘 안에서. 새 단어를 끌어오지 않는다.
6. **정확성 P0** — 원어민이 실제로 쓰는 문장만. 콩글리시·직역투 금지.
7. **PII 금지** — 예한이 실명·나이·학교 언급 금지.
8. **밈 절제** — 마인크래프트·로블록스 감성은 OK, 아재 개그·유행 지난 밈 금지. 이모지 문장당 0~2개.
9. `tts`에 대괄호·별표 등 화면 기호 금지.

## 6. 저작 전에 반드시 할 것

배정받은 모듈의 **기존 콘텐츠를 먼저 읽으세요.**
- learn 카드가 무엇을 가르쳤는지 → 소환 문항은 **그것을 조립시키는 것**이어야 한다
- 그 모듈이 쓰는 어휘·캐릭터·말투 → 그대로 따른다
- 이미 나온 문장을 그대로 재사용하지 않는다(같은 규칙, 다른 문장)

## 7. 자가 검수 체크리스트

- [ ] items가 정확히 3개, id가 `<모듈>-SM-1~3`
- [ ] 정답 토큰을 순서대로 공백으로 이으면 `answer`와 **완전 일치**(대소문자·부호 포함)
- [ ] `answer` 끝에 마침표 없음
- [ ] tokens 4~7개, 중복 없음, 오답 블록 1~2개 포함
- [ ] **다른 순서로 조립해도 맞는 문장이 되는 경우가 없는가** (직접 순열을 따져볼 것)
- [ ] `scene`이 있으면 actor·verb·object가 문장과 **100% 일치**, 동사 제약 준수
- [ ] `scene`을 넣을 수 없는 문장에 억지로 넣지 않았는가
- [ ] `tts`와 `voice`가 함께 있는가, tts가 answer와 같은 순수 영어인가
- [ ] 감점·질책·비교·능력 칭찬 문구가 하나도 없는가
- [ ] 그 모듈이 가르친 문법을 실제로 조립시키는가 (단순 단어 나열이 아닌가)
